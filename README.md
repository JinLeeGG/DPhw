# DPhw

피해, 회복, 보호 토큰, 배수 토큰이 있는 격자에서 살아서 도착할 수 있는 경로를 찾는 동적 계획법(DP) 풀이입니다.

## 실행

Python 3.10 이상을 사용합니다. 추가 패키지는 필요하지 않습니다.

```sh
python3 main.py examples/basic.txt
```

파일 내용을 표준 입력으로 전달해도 됩니다.

```sh
python3 main.py < examples/basic.txt
```

예제 출력:

```text
Path found:
(0, 0) mental=5 action=start
(0, 1) mental=2 action=take_damage
(1, 1) mental=4 action=heal
```

도달 불가능하면 `No path exists.`를 출력합니다. 가능한 경로 중 하나를 출력하며,
각 줄에는 좌표, 해당 칸의 효과를 적용한 후의 정신력, 선택한 행동을 표시합니다.
잘못된 입력은 오류 메시지와 종료 코드 2로 처리합니다.

## 입력 형식

첫 줄에는 `n M`, 이후 `n² - 1`줄에는 `x y t v`를 넣습니다.
좌표는 0부터 시작하며 코드에서는 `x`를 행, `y`를 열로 사용합니다.
시작 칸 `(0, 0)`은 비어 있으므로 입력에 넣지 않습니다. 칸 기록의 순서는 자유입니다.

| t | 효과 | v |
| --- | --- | --- |
| 0 | 피해 | 잃는 정신력 |
| 1 | 회복 | 얻는 정신력 |
| 2 | 보호 토큰 획득 | 0 |
| 3 | 배수 토큰 획득 | 0 |

오른쪽 또는 아래로 이동하며, 도착점은 `(n-1, n-1)`입니다.
정신력 0은 유효하지만 음수는 실패입니다. 시작 정신력이 음수이면 즉시 실패합니다.
각 토큰은 최대 한 개씩 보유하며, 서로 다른 토큰은 동시에 보유할 수 있습니다.
보호 토큰은 피해를 한 번 막고, 배수 토큰은 회복량을 한 번 두 배로 만듭니다.
토큰을 사용하면 소모됩니다. 같은 종류를 다시 얻어도 보유 개수가 늘어나지는 않습니다.

배수 토큰은 회복 칸에서 사용 여부를 선택하고, 사용하지 않으면 계속 보유하는 것으로
해석했습니다. 과제 설명에서 토큰 소모는 사용 시 발생한다고 설명한 것에 따른 해석입니다.

## 이해하는 순서

1. `read_problem`: 입력으로 격자를 구성합니다.
2. `enter_tile`: 한 칸에 들어갈 때 가능한 행동들을 구합니다.
3. `solve`: 각 칸과 토큰 상태에 도달할 수 있는 최대 정신력을 저장합니다.
4. `previous`: 이전 칸, 이전 토큰 상태, 행동을 기록하여 실제 경로를 복원합니다.

### DP 상태

```text
best[row][col][tokens]
```

이 값은 **해당 칸의 효과를 처리한 뒤, 해당 토큰을 가진 상태로 남길 수 있는 최대 정신력**입니다.
도달할 수 없으면 `-1`을 저장합니다.

| tokens | 보호 | 배수 |
| --- | --- | --- |
| 0 | 없음 | 없음 |
| 1 | 있음 | 없음 |
| 2 | 없음 | 있음 |
| 3 | 있음 | 있음 |

시작 상태는 `best[0][0][0] = M`입니다. 각 도달 가능한 상태에서 오른쪽과 아래 칸으로 이동합니다.
피해 칸에서는 그냥 피해를 받거나 보호 토큰을 쓰는 경우를,
회복 칸에서는 일반 회복을 받거나 배수 토큰을 쓰는 경우를 각각 고려합니다.
음수가 되는 이동은 버립니다. 토큰 획득은 해당 보유 비트를 켭니다.

**같은 칸과 같은 토큰 상태라면 정신력이 더 큰 경우만 남겨도 됩니다.**
정신력이 작은 경우가 할 수 있는 모든 후속 행동은 큰 경우에도 가능하기 때문입니다.
토큰 상태가 다르면 나중에 가능한 행동이 달라지므로 따로 저장해야 합니다.

위에서 아래로, 각 행에서는 왼쪽에서 오른쪽으로 처리하면 각 칸의 두 선행 칸이 먼저 처리됩니다.
따라서 각 칸을 처리할 때 기록된 최대 정신력이 확정되어 있습니다.
도착점의 네 상태가 모두 `-1`이면 경로가 없고, 하나라도 유효하면 이전 기록을 따라 경로를 복원합니다.

### 복잡도

칸마다 토큰 상태 4개, 다음 이동 최대 2개, 행동 최대 2개만 확인합니다.

- 시간: **O(n²)**
- 공간: **O(n²)** (최대 정신력과 경로 복원 기록)

정신력 `M`을 배열 크기나 반복 횟수로 사용하지 않습니다.
일반적인 알고리즘 분석처럼 정수 연산을 상수 시간으로 취급한 복잡도입니다.

## 검증

직접 작성한 테스트를 실행합니다.

```sh
python3 -m unittest discover -s tests -v
```

테스트에는 정신력 0 경계, 음수 시작, 토큰 보관/소모/중복 획득, 두 토큰 동시 사용,
경로 재실행 검증, 작은 무작위 격자 400개에 대한 완전탐색과의 비교,
`100 × 100` 격자, 큰 `M`, 입력 오류 및 실행 명령 검증이 포함됩니다.

제공된 수업 테스트 ZIP은 로컬 경로로 연결할 수 있습니다.
ZIP 내부에서 각 입력 파일의 상위 폴더가 `true` 또는 `false`여야 합니다.

```sh
COURSE_TEST_ZIP="/path/to/tests.zip" python3 -m unittest discover -s tests -v
```

`COURSE_TEST_ZIP`을 지정하지 않으면 수업 테스트 항목만 건너뜁니다.
수업 PDF와 제공 테스트는 저장소에 포함하지 않습니다. `examples/`와 `tests/`의 예제는 직접 작성했습니다.
